# PN diodes are used as switches
stimulation link : https://www.tinkercad.com/things/2eS490Q5aLv-powerful-maimu
# RESULT : Demonstrating switching 
Condition 1: Forward bias (ON)
- Battery positive → Diode Anode.
- Battery negative → Diode Cathode side of the overall circuit (LED negative).
- LED glows.
Condition 2: Reverse bias (OFF)
Reverse the PN diode:
- Battery positive → Diode Cathode.
- Battery negative → Diode Anode side.
The LED turns OFF.
Expected result
Diode condition	LED
Forward bias	ON
Reverse bias	OFF 
# Zener diodes are used as voltage regulators
stimulation link : https://www.tinkercad.com/things/bIKkDsGI9zp-smooth-rottis
# RESULT : When a 9V DC input supply was applied, the Zener diode maintained an approximately constant output voltage of 5.1V across the load resistor.

Expected output:
- Input voltage: 9V
- Zener voltage: 5.1V
- Output voltage: Approximately 5.1V
Conclusion: The experiment demonstrates that a Zener diode operating in reverse breakdown maintains a nearly constant output voltage, even when the input voltage varies within its regulation range.
